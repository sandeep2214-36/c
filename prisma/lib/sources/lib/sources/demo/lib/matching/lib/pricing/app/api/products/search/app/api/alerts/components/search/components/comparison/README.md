# Multi-Source Product Comparison Web Application

A modern, production-ready product price comparison platform built with Next.js, TypeScript, Tailwind CSS, PostgreSQL, and Prisma.

## Features
- **Multi-Source Adapter Architecture:** Pluggable adapters for structured data ingestion.
- **Intelligent Product Matching Engine:** Fuzzy matching on brand, model number, storage, RAM, and GTIN.
- **Transparent Best Deal Scoring Algorithm:** Customizable weighted scoring based on price, rating, reviews, and delivery.
- **Price Drop Alerts & History Charts:** Track price trends over time with automated email/in-app notification hooks.
- **Secure Admin Dashboard:** Manage data sources, sync frequency, and scoring weights.
